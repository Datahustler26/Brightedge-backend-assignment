                     System Architecture Overview (Part 2: Billions Scale)
                

                5 Billion URLs / Month
            

            

                

                    
 1. Ingestion Layer

                    
Batch ingestion from MySQL / S3 dumps streaming into domain-partitioned Kafka topics with Bloom Filter deduplication (~6.2 GB RAM for 5B URLs).

                

                

                    
 2. Distributed Crawler

                    
Kubernetes HPA Auto-scaler with Spot instances running async workers, CoreDNS caching, and per-domain politeness token buckets.

                

                

                    
 3. Unified Storage

                    
ClickHouse Columnar DB for sub-second SQL analytics, OpenSearch for full-text topic search, and AWS S3 ZSTD Parquet lake saving 80% storage cost.

                

                

                    
 4. Observability & SLOs

                    
99.9% Availability SLA, P95 < 2s crawl latency, 11 9s durability with Prometheus/Grafana real-time metrics tracking queue lag.
